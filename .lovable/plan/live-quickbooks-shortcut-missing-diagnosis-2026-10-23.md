# Live QuickBooks shortcut missing: diagnosis

## Verified (read-only)
- The live site (getaquaclear.com and aquaclear-pools.lovable.app) serves the same current version, and it already includes the "QuickBooks Connection" Quick Action, the QuickBooks menu item and the /admin/quickbooks page.
- So it is not unpublished changes and not a missing link. The shortcut only shows for admins, but you are on the admin dashboard, so permission is unlikely.

## Most likely cause
Your phone or browser is still showing an older saved copy of the app (the Home Screen app keeps old versions).

## Fix (no changes needed from me)
1. In the app, tap your initials (top right), then "Refresh app". Or close the app fully and reopen it.
2. If it is still missing: open https://getaquaclear.com/?sw=off in Safari, sign in, and check the dashboard.
3. If that works, remove the old Home Screen icon and add it again from Safari (Share, then Add to Home Screen).
4. If it's still missing after that, tell me the device and browser you used and I'll look further.
